# memory-card
для запуска самого квиза требуется установленный на компьютере Python(от 3.13) с установленными библиотеками PyQt5,/любой редактор кода(например, VSCode)
после запуска можно ознакомиться с вопросом и выбрать правильный вариант ответа, всего вариантов ответа на каждый вопрос - 4!
каждый ответ учитывается в статистике, статистика обновляется и выводится после ответа на вопрос.
Всего в таблице есть три критерия - кол-во отвеченных вопросов, счёт правильных ответов и РЕЙТИНГ(правильные вопросы:отвеченные вопросы*100)
приятного использования!!
